# The DelQuro Files

A mobile-first **build log & project tracker** in a single HTML file. Log your
ideas instantly and always get straight back to the project in **Arena.ai** or
**GitHub.com**.

- **Zero dependencies** — open `index.html` in any browser, or host it on
  GitHub Pages. No server, no install, no build step.
- **Mobile-first** — bottom tab bar, a "+" quick-capture button, thumb-size
  touch targets, and bottom-sheet forms. Works great on desktop too.
- **Logs everything** — ideas, projects, change log, builds, code snippets, and
  conversations, plus a merged Master Log and full-text search.

## Use it

- **Open** `index.html` in a browser (double-click it).
- **Log fast** — tap the **+** button (or the capture bar on desktop).
- **Deep links** — each project holds an "Open in Arena.ai" and "Open in
  GitHub" button, so you can jump straight to the real thing.

## Where your data lives

Your data is saved **in your browser** (localStorage) — it never leaves your
device. Use **Export/Import** for file backups, or copy a **sync code** to move
your data between devices — no login, no server. (Tip: drop your backup file into this repo so it's saved
online too.)

## Hosting on GitHub Pages

1. Upload these files to a new GitHub repository.
2. Repo **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**.
3. Open `https://YOURUSERNAME.github.io/REPO-NAME/`.
